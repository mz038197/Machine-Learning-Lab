# 路考拆成獨立專案，委託放在路考網站上

卷積神經網路的委託是路考，跟其他三份委託不同：它不是實驗夾裡由 `tools/build_briefs.py` 產生的 `委託.html`，而是放在路考網站上，訓練影片也在那裡下載。路考網站部署在 Fly.io，push 就自動部署，所以路考的程式（答案產生、計分、學生訓練程式、網站）搬到公開的 `mz038197/road-test`，本 repo 只在實驗本最後一格留路考網站的網址。

這樣學生開始和交件都在同一個網址，不必在實驗夾的 HTML 和網站之間切換。改線性回歸等章節時，也不會觸發路考網站重新部署。路考的程式本來就沒有 import 本 repo 的東西，拆開不會斷掉相依。

## Considered Options

- **留在本 repo，用 GitHub Actions 的 `paths` 過濾觸發部署**：搬檔案或新增共用模組時，很容易忘了更新路徑。
- **照其他委託做一份 `委託.html`，再連到網站**：學生要多切換一次。
