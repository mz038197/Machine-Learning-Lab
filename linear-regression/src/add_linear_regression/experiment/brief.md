# 台北二高麗菜均價

2024 到 2026，台北二的高麗菜批發。請估計每一天的平均價。

資料在 `data/taipei2_cabbage.csv`。欄位有日期、月份、平均價（元/公斤）、上價（元/公斤）、下價（元/公斤）、交易量（噸）、台北近30日均溫（℃）、台北近7日雨量（毫米）。要預測的是「平均價（元/公斤）」。

可以考慮的欄位：

- 月份
- 交易量（噸）
- 台北近30日均溫（℃）
- 台北近7日雨量（毫米）

「上價（元/公斤）」「下價（元/公斤）」是同一天的價格，不要拿來當特徵。

天氣有空白。程式用這個專案已經裝上的 numpy、matplotlib、scikit-learn。

請在 `cabbage_pricing.ipynb` 裡完成。一次請 AI 寫一格，跑過、看懂，再進行下一格。最後「你的判斷」自己寫，不要請 AI 寫。

做完要有：

- 這次用了哪些欄，前處理留下多少列
- 有沒有因尺度不同而縮放
- 訓練後的係數
- 一張看得出貼合程度的圖
- 你自己的判斷：交易量變多時價格怎麼走，溫度或雨量有沒有改這個判斷
